<img width="100%" src="assets/sec-about.svg" alt="About me. I'm a full-stack developer who likes to take a product from the idea to production: design, API, mobile app, tests and deploy. My main project, LightWeight, is a real fitness product with a mobile app, a REST API, a trainer-client marketplace and a chat, and it is being prepared for the stores. I write the tests first and keep the logic in small pure functions, so the components only render. I care about the details that make an app feel finished: safe areas on notched phones, no overflow at 320 px, accessible labels, dark mode. I review my own diffs before anyone else sees them, and I keep one branch per feature with a clean history.">

Routines: Creation wizard (sets, rep range, rest and RIR per set), weekly calendar, guided workout with rest timer, and a draft that survives closing the app. Progress: Session history, per-exercise evolution and weekly volume per muscle group. Coaching: Clients find a trainer and hire a service; trainers manage clients, requests and routines; chat with text and photos. Admin: Verification of trainers' qualifications and refunds. Nearby gyms: Map of gyms around you, built on OpenStreetMap data. Native: Android and iOS with Capacitor, local notifications for the rest timer.">
